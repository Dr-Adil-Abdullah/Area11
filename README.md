## ⏪ واپس جانا (Save / Go Back) — تیار ہے ✅

ہر مرحلے پر ایک **save point** بن جاتا ہے۔ کبھی بھی کسی پرانی سٹیج پر واپس جا سکتے ہیں — **اور کچھ بھی ضائع نہیں ہوتا**۔

```bash
bash scripts/ckpt.sh save "کام کا نام"   # ✅ سٹیج محفوظ کرو
bash scripts/ckpt.sh list                 # 📋 ساری سٹیجیں دیکھو
bash scripts/ckpt.sh go 3                 # ↩️ سٹیج 3 پر جاؤ
bash scripts/ckpt.sh undo                 # ↩️ پچھلی سٹیج پر جاؤ
bash scripts/ckpt.sh diff 2               # 🔍 سٹیج 2 سے اب تک کیا بدلا
bash scripts/ckpt.sh status               # ℹ️ ابھی کا حال
bash scripts/ckpt.sh push                 # ☁️ گٹ ہب پر محفوظ
```

**سب سے خاص بات:** `go` یا `undo` کرنے سے پہلے یہ نظام **خود بخود** آپ کا موجودہ (بغیر محفوظ کیا) کام سنبھال لیتا ہے۔ یعنی اچانک واپس جانے سے بھی کچھ ضائع نہیں ہوتا۔
