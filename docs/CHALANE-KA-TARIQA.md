## 🟢 حصّہ 1: **ابھی** دیکھنے کا سب سے آسان طریقہ (لائیو پریویو)

بس میں نے ایک **سرور چلا رکھا ہے** — اوپر/ساتھ میں **«Area11 app»** والا خانہ نظر آ رہا ہے،
اس پر کلک کریں تو ایپ **ویسے ہی کھل جاتی ہے** (جیسے کوئی ویب سائٹ)۔

اس میں آپ کر سکتے ہیں:

| دیکھیں | کیسے |
|---|---|
| **لاگ ان** | مالک کا پاس ورڈ: **`area11`** |
| **بکری (Counter)** | `/pos` — دوا ڈالیں، کیش دیں، باقی رقم خود نکلتی ہے، رسید چھاپیں |

> **نوٹ:** یہ پریویو **میرے کمپیوٹر (sandbox)** پر چل رہا ہے — یہ **مستقل ویب سائٹ نہیں**۔
> جب یہ بند ہو جائے تو آپ کے اپنے کمپیوٹر پر حصّہ 2 کے مطابق چلائیں (وہی ایپ، وہی ڈیٹا فارمیٹ)۔

## 🟢 حصّہ 2: **اپنے کمپیوٹر** پر چلانا (اصل اور مستقل طریقہ)

کچھ بھی «انسٹال» نہیں کرنا — صرف **Node.js** (جو پہلے سے درکار ہے) اور **ایک فولڈر**۔

### قدم 1 — Node.js موجود ہے؟ (ایک بار)
ایک کالی سی کھڑکی (Terminal / Command Prompt) کھولیں اور لکھیں:

```bash
node -v
```

- اگر **`v22`** یا اس سے اوپر لکھا آئے → تیار ہے، قدم 2 پر جائیں۔
- اگر «not found» آئے → [nodejs.org](https://nodejs.org) سے **LTS** (سبز بٹن) ڈاؤن لوڈ کر کے انسٹال کر لیں (بس Next → Next → Install)۔

> ڈیٹا بیس (SQLite) Node کے **اندر** پہلے سے موجود ہے — الگ سے کچھ انسٹال نہیں کرنا۔

### قدم 2 — ایپ اپنے کمپیوٹر پر لائیں (ایک بار)
```bash
git clone https://github.com/Dr-Adil-Abdullah/Area11.git
cd Area11
npm install        # 2-3 منٹ، ایک بار
```

(اگر `git` نہیں ہے تو GitHub پر سبز **Code** بٹن → **Download ZIP** → کسی فولڈر میں کھولیں،
پھر اسی فولڈر میں Terminal کھول کر اوپر والا `npm install` چلائیں۔)

### قدم 3 — چلائیں (ہر روز یہی)
```bash
cd Area11
npm start
```

نیچے کچھ ایسا آئے گا:
```
▲ Next.js 15.5.26
- Local:   http://localhost:3000
✓ Ready
```

### قدم 4 — براؤزر میں کھولیں
اپنے براؤزر میں جائیں: **http://localhost:3000**
پہلی بار مالک کا پاس ورڈ: **`area11`**

### ⚠️ سب سے پہلا کام (لازمی)
1. **Settings → Staff** میں جا کر **مالک کا پاس ورڈ بدلیں** (`area11` چھوڑیں نہیں)۔
2. عملے کے لیے **PIN** بنائیں (مثلاً کیشیئر کا 4 عددی PIN)۔
3. **Settings → Backup** سے ایک **`.zip` بیک اپ** لیں اور کہیں محفوظ کر لیں۔

### روکنا / بند کرنا
Terminal میں `Ctrl + C` دبائیں۔ (ڈیٹا محفوظ رہتا ہے — وہ `Area11/data/area11.db` میں ہے۔)

## 🟢 حصّہ 3: **ویب سائٹ کی طرح** استعمال کرنا (گھر سے، یا کہیں بھی)

یہاں **سمجھنا ضروری ہے**: یہ ایپ ڈیٹا ایک **فائل** (`data/area11.db`) میں رکھتی ہے۔
اس لیے **عام فری ہوسٹنگ (Netlify / Vercel / GitHub Pages)** اسے **نہیں** چلا سکتی
(وہ ہر بار نئی کاپی بنا کر پرانی مٹا دیتے ہیں)۔
اس کا **فائدہ** یہ ہے کہ آپ کا ڈیٹا **آپ کے پاس** رہتا ہے — انٹرنیٹ بند ہو تب بھی ایپ چلتی ہے۔

آپ کے پاس **تین راستے** ہیں:

### (الف) سب سے آسان: **دکان کا کمپیوٹر ہی سرور ہے** ✅ (میرا مشورہ)
1. دکان کے کمپیوٹر پر `npm start` چھوڑ دیں۔
2. دوسرے کمپیوٹر/موبائل (جو **اسی وائی فائی** پر ہوں) سے کھولیں:
   ```
   http://192.168.1.X:3000      ← یہ «X» دکان کے کمپیوٹر کا IP ہے
   ```
   IP جانچنے کا طریقہ (دکان والے کمپیوٹر پر Terminal میں):
   ```bash
   ipconfig          # Windows
   ifconfig          # Mac / Linux
   ```
   جو «IPv4 Address» لکھا ہو وہی نمبر استعمال کریں۔
3. **فائدہ:** مفت، تیز، انٹرنیٹ نہ ہو تب بھی چلتی ہے، ڈیٹا آپ کے پاس۔

### (ب) گھر سے دکان کے کمپیوٹر تک رسائی (دور سے دیکھنا ہو تو)
کمپیوٹر کو انٹرنیٹ پر محفوظ طریقے سے سامنے لانے کے لیے:
- **Tailscale** (سب سے آسان، مفت): دونوں کمپیوٹر پر انسٹال کریں → ایک ہی «نیٹ ورک» بن جاتا ہے →
  پھر گھر سے `http://<tailscale-IP>:3000` کھولیں۔
- یا **ngrok / Cloudflare Tunnel** (ایک کمانڈ، عارضی لنک)۔

### (ج) کلاؤڈ پر (اگر واقعی «ویب سائٹ» چاہیے تو)
**Node چلانے والی** ہوسٹنگ درکار ہے جس میں **مستقل ڈسک** ہو:
- **Railway** / **Render** / **Fly.io** / **DigitalOcean VPS** / **Hetzner**
  (ان میں «Volume / Persistent Disk» کا آپشن لیں اور `data/` وہیں رکھیں)

سیٹ اپ کا خلاصہ:
```bash
# سرور پر
git clone https://github.com/Dr-Adil-Abdullah/Area11.git
cd Area11 && npm install && npm run build
npm start -- -H 0.0.0.0 -p 3000
```
پھر اپنی ڈومین (مثلاً `area11.com`) کو اسی سرور کی طرف موڑ دیں۔

> ⚠️ **Netlify / Vercel / GitHub Pages پر یہ ایپ نہیں چل سکتی** — وہ صرف پرانا
> **Vite ڈیمو** (`legacy-demo-vite/`) دکھا سکتے ہیں، جس میں بکری/اسٹاک کا اصلی کام نہیں ہے۔
> تفصیل: `HANDOFF.md` §10 اور `docs/SUPABASE.md`۔
